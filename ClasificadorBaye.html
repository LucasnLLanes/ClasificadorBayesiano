1. Introducción

El algoritmo Naive Bayes es un clasificador probabilístico basado en el teorema de Bayes, que asume independencia condicional entre las características. En este trabajo se aplica la variante Multinomial para clasificar textos de noticias en dos clases: real y fake. Se complementa el desarrollo con validación cruzada estratificada para obtener una estimación más estable del rendimiento.

2. Planteo del problema

Se busca construir un modelo capaz de distinguir noticias verdaderas de falsas a partir de su contenido textual. Para ello se utiliza un conjunto reducido de 10 noticias etiquetadas, suficiente para mostrar el funcionamiento del flujo completo.

noticias = {

    'categoria': ["real","fake","real","fake","real",
                  "fake","real","fake","real","fake"]
}

3. Desarrollo de la solución

3.1 Vectorización del texto

El texto se transforma en una matriz de conteo de términos mediante CountVectorizer.

vectorizador = CountVectorizer()
X_train_vec = vectorizador.fit_transform(X_train)

3.2 Entrenamiento del clasificador

Se emplea MultinomialNB, adecuado cuando las características representan frecuencias de palabras.

modelo = MultinomialNB()
modelo.fit(X_train_vec, y_train)

3.3 Validación cruzada

Se aplica StratifiedKFold con 5 particiones para conservar la proporción de clases en cada fold.

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=2026)
scores = cross_val_score(pipeline, X, y, cv=cv, scoring='accuracy')

6. Conclusiones

El clasificador Naive Bayes Multinomial mostró un desempeño sólido sobre el conjunto de prueba, con una exactitud perfecta, aunque debe interpretarse con cautela por el tamaño reducido del dataset. La validación cruzada arrojó una precisión media del 80% con cierta variabilidad entre folds, lo que refleja la sensibilidad del modelo ante pocos datos. Como trabajo futuro se propone ampliar el corpus, aplicar TF-IDF y evaluar con métricas por clase.
